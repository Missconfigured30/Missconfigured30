## 🧩 Featured Work

### 📚 Documentation Automation

**DocSync Auditor**

A Python-based documentation auditing and indexing workflow created to solve a real documentation-management problem.

The project works with large document repositories to:

* Read and process repository data
* Identify required documents
* Scan available documentation
* Build a structured document index
* Help identify documentation gaps and mismatches
* Reduce repetitive manual verification

**Tech:** Python · Pandas · OpenPyXL · python-docx
